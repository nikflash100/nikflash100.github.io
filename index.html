Projects

Buzzer Station

A quizbowl practice app that reads questions word by word so you can buzz in with the spacebar, like a real match. I made it because I wanted to practice on my own.

Built with: HTML, JavaScript

What I did: Wrote a parser that pulled 3,531 questions (1,885 tossups and 1,646 bonuses) out of public packet archives. Added power markers, auto-grading, scoring by category, and a mode to redo questions I missed. The parsing was the hardest part because the packets are formatted inconsistently.

From Failure to Flourishing

A data analysis project looking at what affects whether students fail, using a dataset of student info.

Built with: Python, pandas, matplotlib, seaborn

What I did: Cleaned the data and made graphs comparing failure rates against absences, study time, parental support, and other factors. I learned how to pick the right type of chart for each comparison.

SuccessForecast

A machine learning model that predicts whether a student will pass or fail.

Built with: Python, scikit-learn

What I did: Trained a logistic regression model that got 85.6% accuracy and 0.92 ROC-AUC. Also used K-Means clustering to group students into types based on performance. Presented it at demo day.

Code isn't public yet.

Signal

A diagnostic app for K-12 students that figures out which topic they're weakest in.

Built with: Thunkable, OpenAI API (gpt-4o-mini)

What I did: Designed a 16-question screening quiz that narrows down to the weak topic, with a backup question bank so it still works offline. Presented it at the Spark Civics Civic Innovation Showcase.

Built in Thunkable, so there's no code repo.
